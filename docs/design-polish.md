# Portfolio visual refinement

Researched and implemented: 2026-10-05. Current direction removes the generated sculptures, restores a painted Library background, and uses generated material scans to reveal each chapter beneath the preceding page.

## Design and implementation

Four sheets retain the original sketch, canvas, glass, and pixel themes. Selected projects and About share one continuous glass sheet, with About preserved as a navigation anchor. Live typography, construction guides, original canvas drawings, real project captures, the existing WebGL glass study, and the original pixel landscape supply the visuals. The two generated sculptures and their delivery files were removed. The user's latest direction restores paint texture with a newly generated local coral canvas tile.

Section anchors stay in normal document flow while their visual surfaces translate vertically. Supported browsers use native CSS view timelines in `app/atelier.css`, with no JavaScript writes to page transforms during scrolling. Each incoming sheet waits beneath the outgoing page, then glides through a quadratic handoff over the last 20% of entry. Its velocity joins normal scrolling continuously. The revised implementation removes rotation, oscillating lift, scaling, and rectangular box shadows. Long sections retain their full scrollable length, and reverse scrolling reverses the reveal. `components/page-stack.tsx` caches layout positions until ResizeObserver reports reflow, maintains nested anchor alignment, and supplies the same curve through a scheduled-frame fallback for browsers without view timelines. Transform values no longer invalidate inherited variables throughout each page. Keyboard focus reveals covered controls. Cleanup removes observers, listeners, and pending frames.

All three boundaries belong to their outgoing sheets. `components/material-edge.tsx` now displays transparent scans of torn rag paper and coral dry-brush paint, replacing the artificial canvas contours. The scans use CSS backgrounds at a constant proportional scale with horizontal repetition and a short upper color blend. The Library's square painted texture repeats at an 800px scale and fades into the coral base at its bottom. `PixelLandscape`'s `page-edge` variant still draws the dark glass/About contour using the existing animated pixel tongues. The landscape paints its entire upper sky directly beneath that outgoing edge. Paper and paint require no independent frame loops; the page controller supplies their motion and honors pause/reduced motion. Shadows follow the transparent silhouettes. The pixel canvas retains its four-pixel grid and unblurred contour. Nested anchors compensate for surface translation with `scroll-margin-top`; the root's existing scroll padding supplies navigation clearance.

The tools heading and controls now have light text on navy. Its detail surface uses dark text on a light background: heading #172b45, body #273d56, secondary text #3a526b, background #edf2f7. The previous dark surface inherited dark lettering and caused the reported readability problem.

The page reveal and existing pointer depth honor both the manual motion control and reduced-motion preferences. Native browser scrolling and anchors remain in use. No scroll library, rendering framework, runtime API, external image service, or production dependency was added. Existing versions remain Next.js 16.3.4 and React 19.2.6. Native platform APIs require no purchase or new software license; no external implementation was copied.

The stutter follow-up also batches pointer-depth geometry reads before writes and ignores scenes without depth layers. The glass study now follows the pixel scene's existing visibility-aware scheduling approach: it cancels its animation callback when offscreen or the document is hidden, resumes when visible, and reacts to reduced-motion changes. Its drawing algorithm and appearance are preserved.

## Source record

- [Chrome scroll-driven animation guide](https://developer.chrome.com/docs/css-ui/scroll-driven-animations) and its author's [stacking cards example](https://scroll-driven-animations.style/demos/stacking-cards/css/): working layered-scroll reference and native off-main-thread transform mechanism. The guide explains why asynchronous scroll listeners can lag compositor scrolling. This site's surface translation and handoff curve are project-specific integration, validated locally. Native timelines are feature-detected, with no polyfill or dependency. Physical-device performance has not been measured.
- [MDN view-timeline-name](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/view-timeline-name) and [animation-range](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/animation-range): named parent timelines and entry range. The timeline has explicit zero inset so root navigation padding does not shift the animation. [CSSWG issue 14364](https://github.com/w3c/csswg-drafts/issues/14364), inspected through the connected GitHub MCP, discusses transform geometry and links relevant Web Platform Tests. This site uses normal HTML layout markers as timeline subjects; decorative SVGs remain descendants, avoiding that SVG-subject edge case. Native CSS is a browser feature, requires no service or license purchase, and no third-party source was copied.
- [MDN drop-shadow examples and support](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/drop-shadow) and [SVG preserveAspectRatio](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/preserveAspectRatio): native shape-following shadows and responsive SVG silhouettes. These are existing platform features, with no dependency or new service.
- [MDN scroll-margin-top](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scroll-margin-top) and [CSSWG issue 2214](https://github.com/w3c/csswg-drafts/issues/2214): scroll alignment uses the transformed border box plus margin. The integration compensates only the vertical page translation; no custom scrolling engine is introduced. Related transform/overflow discussions were inspected through the connected GitHub MCP.

- [MDN transform-style](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transform-style), and [MDN community issue 25801](https://github.com/mdn/content/issues/25801), retrieved through the connected GitHub MCP: masking and overflow can flatten nested 3D scenes. Foreground depth layers remain independent of page surfaces.
- [MDN community issue 15459](https://github.com/mdn/content/issues/15459), retrieved through the connected GitHub MCP: sticky behavior depends on scrolling ancestors and overflow. The existing site has clipped artwork and tall chapters, so the implementation keeps anchor containers untransformed instead of adding a sticky scroll container.
- [MDN accessibility media queries](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Using_for_accessibility): reduced-motion fallback.
